# Клиент Пробник

React + TypeScript + Vite. Основная инструкция запуска находится в [../README.md](../README.md).

- `npm ci` — установить зафиксированные зависимости.
- `npm run dev` — сервер разработки с прокси `/api` → `127.0.0.1:8000`.
- `npm run build` — проверка TypeScript и сборка в `dist/`.
- `npm run test:e2e` — сквозной тест с временным backend; сначала собрать клиент и установить Chromium.

Все запросы находятся в `src/api/client.ts`. На страницах нет прямого `fetch`.
Типы контрактов — в `src/types/`, форматирование — в `src/lib/format.ts`.
Общие компоненты используются во всех кабинетах. `Workspace` загружает операторские данные,
`StudentWorkspace` — только данные ученика из отдельного API.

Для новой страницы добавьте компонент в `src/pages/`, маршрут в `App.tsx` и пункт навигации
в `layouts/AppLayout.tsx`. Новую серверную операцию добавляйте в API-клиент.
Правила регистрации, баллов, публикации и доступа проверяет backend.
